## 📌 Repository Overview

This repository contains the projects developed during the **Oasis Infobyte Summer Internship Program (OIBSIP)** under the **Java Development** track. Each project is structured into its dedicated directory with full source code, comprehensive documentation, and demonstration screenshots.

---

## 📂 Internship Projects

| # | Project Name | Tech Stack | Description | Links |
| :-: | :--- | :--- | :--- | :--- |
| 1 | [**ATM Interface**](./ATM-Interface/) | `Java` • `OOP` • `CLI` • `Java Time API` | A console-based banking system simulation with multi-attempt authentication, balance inquiry, deposit, withdrawal, peer-to-peer transfers, and timestamped transaction history. | [📁 Project](./ATM-Interface/) • [📖 Docs](./ATM-Interface/README.md) |
| 2 | [**Digital Library Management System**](./Java-Task5-DigitalLibrary/) | `Java 25` • `Spring Boot 3` • `React 19` • `MySQL` • `Bootstrap 5` • `Vite` | A modern full-stack web application for digital library administration featuring book cataloging, issue/return workflows, reservation systems, fine management, and user dashboards. | [📁 Project](./Java-Task5-DigitalLibrary/) • [📖 Docs](./Java-Task5-DigitalLibrary/README.md) |
